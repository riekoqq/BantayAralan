# GPU (CUDA) support for torch is NOT handled by a plain
# `pip install -r requirements.txt` -- PyPI's default torch wheel is
# CPU-only (or may not match your CUDA version). If you have an NVIDIA
# GPU, install torch/torchvision FIRST with the matching CUDA build, e.g.
# (check https://pytorch.org/get-started/locally/ for the current command
# for your CUDA version):
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
#
# Then install everything else below. Without a GPU, skip that step --
# ultralytics will install a CPU-only torch automatically and inference
# will just be slower (still correct, not broken).
